\begin{abstract}
We analyze an authorization decision inconsistency recorded in SAGA.
Direct matcher calls return permission when a specific denial precedes
wildcard permission, although most-specific semantics require denial;
reversing the rules changes the implementation result. Independent finite
specification evaluation and a checked observation supply a fixed symbolic
scenario. Under explicit assumptions, ProVerif reports message acceptance
reachable and establishes its correspondence to prior token issuance.
Separately, A/A, D/D, and D/A consumer experiments execute production
authorization logic in a controlled environment. D/A reaches one-time-key
release and receiver token issuance, sending, and storage. The empirical
endpoint precedes message acceptance. These results establish neither
a deployed-service exploit nor Python/ProVerif refinement.
\end{abstract}
