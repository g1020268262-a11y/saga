\begin{summary}
We analyze an order-dependent authorization inconsistency in SAGA:
a later wildcard allow can override a more-specific deny because the
matcher fails to retain the best pattern. Controlled production consumers
propagate this decision to token issuance/storage. Under the fixed divergence,
ProVerif reports symbolic \texttt{ChatAccept} reachable with prior
\texttt{TokenIssue}.
\end{summary}
