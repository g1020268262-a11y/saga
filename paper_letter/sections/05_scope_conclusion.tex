\section{Scope and Conclusion}
\label{sec:discussion}
\label{sec:conclusion}

Evidence covers one recorded case and tested policies; it establishes neither
complete authorization correctness nor Python--ProVerif refinement. Controlled
consumer execution stops before message acceptance and is no deployment
exploit. We report matcher order dependence, conditional symbolic acceptance
after token issuance, and consumer propagation to token issuance/storage.
