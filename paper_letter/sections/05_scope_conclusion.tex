\section{Scope and Conclusion}
\label{sec:discussion}
\label{sec:conclusion}

Evidence covers one recorded SAGA case and tested policies, not arbitrary
policies. The symbolic abstraction establishes no Python--ProVerif refinement;
controlled execution stops before message acceptance and establishes no
deployed exploit. We report matcher order dependence, conditional symbolic
\texttt{ChatAccept} with prior \texttt{TokenIssue}, and controlled D/A
propagation to token issuance/storage.
